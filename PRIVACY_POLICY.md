# Política de Privacidad

**Última actualización:** junio 2026

## Control de Horas

Esta aplicación no recopila, almacena ni comparte ningún tipo de información personal de sus usuarios.

### Datos de usuario

Control de Horas funciona completamente sin conexión. Todos los datos ingresados en la aplicación (registros de horas, proyectos, sesiones de trabajo) se almacenan exclusivamente en el almacenamiento local del dispositivo del usuario mediante una base de datos local (Room).

La aplicación no envía ningún dato a servidores externos, no utiliza servicios de análisis, publicidad ni seguimiento de ningún tipo.

### Permisos

- **POST_NOTIFICATIONS**: Se solicita exclusivamente para enviar notificaciones locales de recordatorio cuando el temporizador está activo. No se comparte información con terceros.
- **ACCESS_NETWORK_STATE**: Se utiliza únicamente para detectar la conectividad de red y mostrar un indicador visual en la interfaz. No se transmite información a través de la red.

### Servicios de terceros

Esta aplicación no incorpora SDKs de terceros que recopilen datos de usuario.
